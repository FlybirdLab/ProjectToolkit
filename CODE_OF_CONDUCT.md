# Internal Code of Conduct

ToolkitProject is a private engineering repository. All collaborators are expected to keep communication technical, direct, and respectful.

## Expected behavior

- Discuss code and design decisions objectively.
- Keep reviews focused on correctness, maintainability, performance, and project direction.
- Explain blocking review comments clearly.
- Respect private repository access and project confidentiality.
- Disclose uncertainty when a change is experimental or not fully verified.

## Unacceptable behavior

- Sharing private source code, internal documents, or build artifacts outside authorized channels.
- Bypassing review for changes that affect public APIs, module boundaries, security, or dependencies.
- Hiding generated files, local environment paths, or machine-specific configuration in commits.
- Personal attacks, harassment, or hostile communication.
- Misrepresenting AI-generated or externally copied code as manually reviewed project code.

## Enforcement

Repository maintainers may revert changes, restrict access, or block contributions when behavior creates technical, legal, or operational risk for the project.

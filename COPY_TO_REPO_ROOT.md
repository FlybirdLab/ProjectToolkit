# Copy Instructions

This package contains recommended repository foundation files for ToolkitProject.

Copy the contents of this archive to the repository root, then review before committing.

Suggested commit:

```text
docs(repo): add private SDK repository guidelines
```

Review points before committing:

- confirm `LICENSE.md` wording matches the intended private/proprietary policy;
- confirm `README.md` module descriptions match the current repository state;
- confirm `.github` templates fit the hosting platform;
- confirm `.editorconfig` does not conflict with existing formatting rules;
- do not overwrite existing files without checking differences.

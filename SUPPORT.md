# Support Policy

ToolkitProject is a private SDK. Support is limited to authorized internal users and approved downstream projects.

## Supported requests

- build failures;
- platform backend issues;
- public API usage questions;
- module integration problems;
- test failures;
- regression reports;
- dependency setup problems within the approved project environment.

## Unsupported requests

- public redistribution;
- third-party commercial support;
- undocumented external embedding;
- using ToolkitProject as a complete game engine without a higher-level engine layer;
- support for locally modified dependency layouts that are not part of the repository workflow.

## Required information for support

Include:

- branch and commit hash;
- operating system;
- compiler version;
- CMake generator;
- build configuration;
- selected module/backend options;
- full error log or minimal reproduction.
